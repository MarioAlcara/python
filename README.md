# 🍽️ Sistema de Gerenciamento de Restaurantes (CLI)

Um aplicativo em linha de comando (CLI) desenvolvido em Python para cadastrar, listar e gerenciar o status de funcionamento de estabelecimentos gastronômicos. 

Este projeto foi construído para consolidar os fundamentos da linguagem Python, focando em manipulação de dados em memória, fluxo de controle e modularização.

---

## 🚀 Funcionalidades

- **Cadastrar Restaurante:** Registra novos estabelecimentos informando nome e categoria.
- **Listar Restaurantes:** Exibe todos os restaurantes cadastrados formatados em colunas (Nome, Categoria e Status).
- **Alternar Estado:** Ativa ou desativa um restaurante cadastrado com base no nome.
- **Tratamento de Erros:** Validação de entradas numéricas no menu principal para evitar falhas de execução.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Módulo nativo `os`** (para manipulação e limpeza de tela do terminal)

---

## 📖 Como Executar o Projeto

1. Certifique-se de ter o **VS Code ou qualquer editor que tenha linguagem python**  instalado na sua máquina.
2. Abra o arquivo principal do projeto no seu editor e execute no terminal com o comando:
```bash
   python Sabor_Express.py
```
